# 实机验证清单（刷入后按顺序做一遍）

## 0. 进 TWRP

```sh
adb devices           # 应看到 recovery
adb shell getprop ro.product.device   # OWW251
adb shell getprop sys.usb.controller  # 4e00000.dwc3
adb shell cat /sys/class/udc/*/../uevent 2>/dev/null | head
adb shell ls /dev/block/bootdevice/by-name | head
adb shell ls /dev/block/by-name | head
```

两个 by-name 路径都必须有输出，缺任何一个说明 init rc 的 `on fs` 没跑到
（看 `adb shell dmesg | grep -i 'init.*symlink'`）。

USB 排查（adb 不通时先用串口/TWRP 终端看这些）：

```sh
getprop sys.usb.controller          # 必须非空，否则所有 UDC 写入都会失败
getprop sys.usb.config              # adb / mtp,adb / fastboot
ls /sys/class/udc                   # 预期 4e00000.dwc3
ls /config/usb_gadget/g1            # 存在说明 configfs 建好了
cat /config/usb_gadget/g1/UDC       # 必须等于 4e00000.dwc3 才算绑定成功
ls /dev/usb-ffs                     # adb  mtp  fastboot
```

MTP：TWRP 里 Mount 页面打开 "Enable MTP"，PC 上应出现 MTP 设备；
`getprop sys.usb.ffs.mtp.ready` 为 1、`getprop sys.usb.state` 为 `mtp,adb`。

## 1. 挂载

```sh
adb shell ls -l /dev/block/mapper/
adb shell mount | grep -E 'mapper|by-name'
```

* `/dev/block/mapper/` 下应出现 `system / system_ext / vendor / product` 四个 dm 设备。
* TWRP 界面 Mount 页面勾选 `System`、`Vendor`、`Product`、`System_ext`，日志里应显示
  只读挂载成功（这四个分区是 `shared_blocks`，只能 ro）。
* 真实系统内容在 `/system_root/system`（system-as-root 布局），文件管理器进 `/system_root`。
* `/cache` 可读写挂载；`/metadata` 能挂上即可。
* `/data` 是 f2fs 且默认不加密，应能直接挂上；挂不上看 `dmesg | grep -i f2fs`。

## 2. fastbootd

TWRP 里 Reboot → **Fastboot**；或

```sh
adb reboot fastboot
```

PC 侧：

```sh
fastboot devices
fastboot getvar is-userspace        # 期望 yes
fastboot getvar super-partition-name
fastboot getvar partition-size:system
```

`is-userspace: yes` 且 `fastboot devices` 能看到设备 = fastbootd 正常。
如果 PC 端没设备，先 `lsusb` / 设备管理器看是不是 VID 18D1 出现了但没驱动。

## 3. EDL

TWRP 里 Reboot → **EDL**（或 TWRP 终端执行 `rebootedl.sh`，或 `adb reboot edl`）。
PC 设备管理器应出现 **Qualcomm HS-USB QDLoader 9008**。
没出现就说明内核 restart reason 这条链没走通，用按键/短接进 9008。

## 4. /data

默认不加密，Mount → Data 应能直接挂上，文件管理器能看到内容。
挂不上就看 `dmesg | grep -iE 'f2fs|userdata'`。

## 5. 回滚

```sh
adb push stock_recovery.img /tmp/
adb shell su -c 'dd if=/tmp/stock_recovery.img of=/dev/block/bootdevice/by-name/recovery'
```
